# Governing skill: Time Distribution

Session time is a frequent source of ambiguity — always resolve it explicitly during the
interview and encode it precisely in the main-plan.

## Rules
- Confirm total session duration and exactly which blocks it includes.
- If a quiz/Kahoot is mentioned, confirm whether it is carved from the existing blocks or
  added on top. (e.g. "1.5h lecture + 1.5h practice with 15 min quiz" = 3h total, quiz inside.)
- For special session types (talks, ceremonies, demos), define their own distribution.

## Output
For each session type, produce blocks (name, activity, minutes) whose minutes **sum exactly**
to the session's total duration.

## Reference standard distribution (180-min session) — adapt, don't assume
Apertura 10 · Cátedra 50 · Quiz 15 · Pausa 10 · Práctica guiada 30 · Práctica autónoma 45 ·
Cierre 20.
