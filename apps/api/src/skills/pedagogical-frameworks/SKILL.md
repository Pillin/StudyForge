# Governing skill: Pedagogical Frameworks

Apply these as **internal design tools**. NEVER name or explain them to students in the
generated material.

## 5E (primary class structure)
Every planned class follows: **Engage → Explore → Explain → Elaborate → Evaluate**.
- Open with an Engage hook (a question, problem, or surprising fact) — never a cold lecture.
- Explore before Explain: learners attempt or observe before being told the answer.
- Elaborate = applying content to new contexts (not repeating the example).
- Evaluate = a consolidation check (quiz) + a short written reflection.

## Bloom's revised taxonomy
- Write objectives with **observable-action verbs** (define, identify, implement, design,
  evaluate) — never "understand" or "know".
- State the Bloom level for each objective. Progress levels across the course arc.

## UDL / DUA (baseline accessibility)
- Multiple means of representation (oral + written instructions; reference aids).
- Multiple means of action/expression (varied exercise types; a reflection).
- Multiple means of engagement (real-world relevance; error normalization).

## Active learning & PBL
Favor doing over passive listening; anchor practice in realistic problems where it fits.
