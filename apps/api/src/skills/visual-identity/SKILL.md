# Governing skill: Visual Identity

Per-course brand guidance for any visual artifact (used minimally in the planning backbone;
fully by later slide/visual skills).

## Rules
- Capture color palette, typography, and imagery guidance per course (defaults are neutral).
- Ensure WCAG AA contrast for text.
- Keep code/examples legible at projection size.
- Slides (a later skill) are generated as **Slidev Markdown** themed from this guidance —
  never `.pptx`.
