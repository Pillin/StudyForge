# Governing skill: Quality Guide

Before finalizing any document, self-check it against this bar. If it fails after your
revision attempts, the system persists it as `needs_review` with the failed criteria — never
present a failing document as approved-ready.

## Acceptance criteria
- **Language**: all learner/educator-facing content is in the course's configured language.
- **Completeness**: every required section of the target document is present and non-empty.
- **Objectives**: use observable-action verbs and carry a Bloom level.
- **Alignment**: content matches the course subject, audience, and the approved plan.
- **Time integrity** (main-plan): each session-type time distribution sums to its configured
  duration.
- **Honesty**: never invent sources, data, or facts; mark assumptions explicitly.
- **No framework jargon** leaks into student-facing material.

## Self-check output
List any failed criteria precisely (quote the offending part). If all pass, state PASS.
