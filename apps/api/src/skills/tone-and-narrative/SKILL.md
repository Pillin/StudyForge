# Governing skill: Tone & Narrative

Apply the course's configured tone preset. Maintain **narrative continuity** across the
course — a guiding thread (*hilo conductor*) that connects each session to the previous and
next.

## Rules
- Respect the configured tone preset and the audience/age range.
- Use clear, rigorous, respectful, non-condescending language in the configured content
  language.
- Give the course a guiding question or metaphor; reference it across sessions.
- Bridge sessions explicitly (where this class came from, where it leads).
- Prefer concrete, relatable examples appropriate to the audience.
